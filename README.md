# 🌐 Simple Website Project using Flask

Welcome to this simple web project built with **Flask** using **Python**.  
The goal of this project is to demonstrate a basic Flask setup that can be used as a starting point for learning or building more complex applications.

## ⚙️ Requirements

To run this project locally, you’ll need the following installed:

- Python 3.7 or higher
- pip (Python package installer)

### Install Dependencies

```bash
pip install -r requirements.txt
````

> Tip: It's recommended to use a virtual environment.

## 🚀 How to Run

Once dependencies are installed, start the application using:

```bash
python app.py
```

The app will run at:

```
http://127.0.0.1:5000/
```

## 🗂️ Project Structure

```
.
├── app.py
├── templates/
│   └── index.html
├── static/
│   ├── css/
│   └── js/
├── requirements.txt
└── README.md
```

* `app.py`: Main application file.
* `templates/`: Contains HTML templates.
* `static/`: Contains static files like CSS and JavaScript.
* `requirements.txt`: List of required Python packages.
